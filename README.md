# Teachers' Day Message Card — Sir Randy Bello

A responsive, pink-inspired digital greeting card created with HTML, CSS, and JavaScript to celebrate Teachers' Day.

## Features
- Personalized greeting for Sir Randy Bello
- Teacher portrait displayed on the front of the card
- Interactive open-and-close letter animation
- Light and dark theme toggle
- Responsive layout for desktop and mobile screens
- Subtle decorative details and accessible button labels

## Project files
- `index.html` — webpage structure and greeting message
- `style.css` — layout, colors, typography, and responsive styling
- `script.js` — card interaction and theme toggle
- `Randy.jpg` — portrait used in the greeting card

## How to run
1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a modern web browser.
4. Select **Open your letter** to read the message. Use **Change theme** to switch between light and dark modes.

## Customize
- Edit the message and teacher's name in `index.html`.
- Change colors, fonts, and layout in `style.css`.
- Add or modify interactions in `script.js`.
- Replace `Randy.jpg` with another image, keeping the filename the same, or update the image path in `index.html`.

## Technologies
HTML5 · CSS3 · Vanilla JavaScript
